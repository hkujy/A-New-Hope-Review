# README: Figures and Bibliometric Data

This directory contains the bibliographic data, editable source files, and figures used in the manuscript.

---

### 1. `Figure1 -Systematic methodological and analytical framework.vsdx`
Editable Microsoft Visio source file for Figure 1.  
Presents the systematic methodological and analytical framework, including data collection, bibliometric analysis, systematic review, and scenario analysis.

### 2. `Figure 2-Journal statistic.opju`
Origin project file containing the data, plot settings, and editable source used to generate publication and journal statistics.  
* **Software:** Origin 2021

### 3. `Fig.3 keyword-CO-DESC_v186e209.png`
Exported CiteSpace visualization for the keyword co-occurrence analysis.  
The figure was generated from the data in `"Literature Information Retrieved.txt"` using CiteSpace v.6.4.R1 (64-bit) Advanced.
* **Analysis period:** 2015–2025
* **Time slice:** 1 year
* **Node type:** Keyword
* **Selection criterion:** $g$-index ($k = 25$)
* **Network characteristics:** 186 nodes, 209 links, network density = 0.0121
* **Evaluation metrics:** Modularity $Q = 0.8756$, weighted mean silhouette $S = 0.9975$

### 4. `Fig. 4. Keyword bursts in AB research, 2015–2025.pdf`
Exported CiteSpace visualization showing keyword bursts in autonomous bus (AB) research from 2015 to 2025.  
The analysis was conducted using CiteSpace v.6.4.R1 (64-bit) Advanced based on the bibliographic data in `"Literature Information Retrieved.txt"`.

### 5. `Fig. 5. OA–PA matrix and possible pathways for AB development.pptx`
Editable Microsoft PowerPoint source file for the operator adoption–passenger acceptance (OA–PA) matrix.  
The figure presents four development scenarios defined by different combinations of operator adoption and passenger acceptance, along with possible pathways between them.

### 6. `Literature Information Retrieved.txt`
Bibliographic metadata retrieved from the Web of Science Core Collection, used as the source dataset for bibliometric analysis.
